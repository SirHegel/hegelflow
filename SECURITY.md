# Seguridad de HegelFlow

Este repositorio es privado. Los hallazgos de seguridad no deben publicarse en issues abiertos: repórtalos al propietario del repositorio mediante el canal interno acordado.

No incluyas contraseñas, tokens, cookies, cadenas de conexión, datos personales ni capturas con secretos en el reporte. Describe el escenario, impacto, pasos mínimos de reproducción y versión afectada.

Objetivo de respuesta interno:

- Crítico: contención inmediata.
- Alto: plan de corrección en 24 horas.
- Medio o bajo: priorización dentro del ciclo normal.

Las correcciones deben incluir prueba de regresión, revisión del historial Git y rotación de cualquier secreto potencialmente comprometido.
